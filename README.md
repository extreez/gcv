# gcv

Скилл для кодового агента: по ссылке на документацию сервиса генерации создаёт
работающий CLI, соответствующий единому контракту.

```
/gcv add https://fal.ai/docs
```

Требуется Node ≥ 20.

---

## Что делает

Механика CLI — ретраи, поллинг, идемпотентность, журнал трат, коды выхода,
JSON-конверт, preflight-валидация, предохранители бюджета — уже написана и лежит
в каркасе внутри скилла. Под конкретный сервис заполняется **один файл**,
`src/provider.mjs`, где шесть мест помечены `TODO`:

| Что закрыть | Зачем |
|---|---|
| Эндпоинт баланса | `getBalance` |
| Форма тела запроса создания задачи | `createTask` |
| Эндпоинт статуса | `getTask` |
| Маппинг состояний сервиса на пять состояний контракта | `STATE_MAP` |
| Эндпоинт загрузки файлов | `uploadFile` |
| Источник машинного списка моделей | `refreshCatalog` |

Результат проверяется скриптом: около 80 проверок бесплатными командами, без
реального ключа и без трат.

---

## Команды

| Команда | Что делает |
|---|---|
| `/gcv add <ссылка на доки>` | Подключить новый сервис |
| `/gcv update <service>` | Обновить провайдер под изменившееся API |
| `/gcv verify <service>` | Проверить соответствие контракту |
| `/gcv list` | Какие провайдеры есть и в каком они состоянии |
| `/gcv order` | Порядок обращения к сервисам |

## Установка

### Через skills CLI

```bash
npx skills add extreez/gcv
```

Ставит скилл в `.claude/skills/gcv` текущего проекта. Глобально — флаг `-g`,
для другого агента — `-a <агент>` (например `-a codex`).

### Вручную

```bash
git clone https://github.com/extreez/gcv.git ~/.claude/skills/gcv
```

Или скриптом — он же проверит версию Node:

```bash
./install.sh
```

Windows:

```powershell
.\install.ps1
```

Проверка: в новой сессии `/gcv` появится в списке команд.

Для других агентов путь отличается (`~/.codex/skills/gcv/` и подобные), но
требование одно: копировать **всю папку**, а не один `SKILL.md` — скилл вызывает
скрипты из `templates/`.

templates/scaffold.mjs         копирует каркас и подставляет имена

Всё необходимое лежит здесь же — внешних зависимостей у процесса нет.

## Как это работает

### Шаг 1. Разведка

Агент читает документацию сервиса и отвечает на 11 вопросов, из которых
ключевой — **в какой момент списываются деньги**. Чего не нашёл — записывает как
«не найдено», а не додумывает.

Отдельно описана методика поиска машинного источника цен. Открытого «JSON со
всеми ценами» в документации обычно нет, но сам источник существует: у kie.ai
прайс отдаёт недокументированный эндпоинт, видимый во вкладке Network при
открытии страницы прайсинга. `SKILL.md` описывает порядок такого поиска.

### Шаг 2. Каркас

```bash
node templates/scaffold.mjs --service fal --name "fal.ai" \
  --base-url https://queue.fal.run --docs https://fal.ai/docs \
  --out ~/projects/gcv-fal
```

### Шаг 3. Один файл

Заполняется `src/provider.mjs`. Правила, которые нельзя нарушать:

- `createTask` — `retries: 0`. Автоповтор здесь означает двойную оплату
- `state` приводится к пяти значениям контракта, свои названия не протаскиваются
- `costActual` — только если сервис реально его возвращает, иначе `null`
- Сервис чего-то не умеет → `notSupported()`, а не эмуляция
- Тексты — на английском

### Шаг 4. Проверка

```bash
node templates/verify-contract.mjs ~/projects/gcv-fal
```

Проверяются JSON-конверт, коды выхода, чистота stdout, срабатывание
предохранителей, preflight, отсутствие зависимостей и незакрытых `TODO`. Работа
идёт в изолированном `GCV_HOME` — реальный конфиг и журнал трат не затрагиваются.

Пока проверка не пройдена, провайдер не готов.

### Шаги 5–7

Наполнение каталога, живая проверка на самой дешёвой модели с обязательным
`--max-cost`, создание скилла провайдера.

## Если у сервиса уже есть официальный CLI или MCP

Проверьте: покрывает ли он генерацию, статус, баланс и стоимость? Даёт ли
машинный вывод и стабильные коды выхода?

Оба «да» — используйте официальный, свой создавать не нужно. Хотя бы одно
«нет» — создавайте: оркестратор работает с контрактом, а не с произвольным
инструментом.
