# Архитектура GCV

## Принятые решения

| № | Решение | Почему |
|---|---|---|
| 1 | **Независимые CLI на сервис**, порождаемые из общего шаблона | Максимальная автономность каждого блока. Цена — дублирование механики; компенсируется тем, что код не пишется с нуля, а копируется из проверенного `templates/cli-template` |
| 2 | **Единый контракт вывода** для всех CLI | Без него оркестратор не смог бы говорить с N сервисами. Это единственное, что жёстко связывает независимые пакеты |
| 3 | Node 22, ESM, **ноль зависимостей** | Нативный `fetch`, нативный `--test`, `npx`-установка, тот же язык, что и будущий веб |
| 4 | **Два аппрува** в `/creative`: план без цен → смета | Выбор пользователя. Креатив утверждается отдельно от бюджета |
| 5 | Логика в `src/`, CLI и MCP — тонкие обёртки | Веб-версия импортирует `src/` напрямую |
| 6 | Каталог моделей — **кэш с TTL**, обновляется по команде | `sync` тянет цены и схемы машинно (у kie — прайс-эндпоинт + OpenAPI страниц моделей), но сохраняется и переиспользуется, а не запрашивается на каждый вызов |

## Поток данных при генерации

```
/creative
   │  бриф + профиль пользователя
   ▼
[план]  ── таблица без цен ──► ⛔ АППРУВ 1
   │
   ▼
gcv-{svc} estimate --json     (деньги не тратятся)
   │
   ▼
[смета] ── цены, % от баланса ──► ⛔ АППРУВ 2
   │
   ▼
gcv-{svc} generate --wait --json --max-cost N
   │           │
   │           ├─► POST /createTask ────────► taskId       (деньги списаны здесь)
   │           ├─► GET  /recordInfo (poll) ─► state, progress
   │           ├─► скачивание файлов
   │           └─► ledger.jsonl += строка (est + факт)
   ▼
[отчёт] таблица + index.html + run.json на диске
```

Точка невозврата — `createTask`. Всё, что можно проверить (лимиты модели, наличие
ключа, достаточность баланса, формат референсов), проверяется **до** неё, в preflight.

---

## Почему preflight отдельно от estimate

`estimate` отвечает на вопрос «сколько это будет стоить».
`preflight` — на вопрос «а вообще получится ли». Это разные отказы:

- estimate: «выйдет 240 кредитов, у тебя 180» → диалог о бюджете
- preflight: «модель принимает 3 референса, ты дал 5» → правка плана

Если смешать, пользователь узнаёт о втором уже после списания.

## Обработка сбоев в пачке

Политика задаётся до старта, в `settings.execution.onFailure`:

| Значение | Поведение |
|---|---|
| `retry` | N попыток той же модели (default 2, только при `retryable: true`) |
| `fallback` | Переключиться на резервную модель из плана |
| `skip` | Пропустить задачу, продолжить пачку |
| `abort` | Остановить всё, отчитаться о потраченном |

Default: `retry` → затем `skip`, с явным списком пропущенных в отчёте.
Молчаливое сокращение объёма запрещено: если из 10 картинок вышло 7, отчёт
называет 3 несделанные и причину.

## Идемпотентность

`idempotency-key = sha256(provider + model + JSON.stringify(input) + count)`.
Карта `ключ → taskId` в `~/.gcv/idempotency.json`. Повторный `generate` с тем же
ключом не создаёт задачу, а возвращает существующую. Сброс — `--idempotency-key`
вручную или `--force`.

Это защищает от самого дорогого класса ошибок: агент повторил команду после
обрыва связи и заплатил дважды.

## Хранение результатов

```
<vault>/creatives/2026-08-11/run_20260811_143000/
  ├ files/
  │   ├ 01_cover_nano-banana.png
  │   └ 02_cover_seedream.png
  ├ run.json        полный манифест: бриф, план, промпты, модели, est/факт, хэши
  ├ index.html      автономная галерея (инлайн CSS, без внешних запросов)
  └ prompts.md      промпты в читаемом виде
```

`<vault>` по умолчанию — папка проекта. Проект лежит в Яндекс.Диске, поэтому
облачная синхронизация получается бесплатно. Отдельные storage-адаптеры (s3,
gdrive) — точка расширения `settings.storage.adapter`, сейчас только `local`.

## Границы слоёв

Что **нельзя** делать:

- `/creative` не вызывает HTTP-API сервисов напрямую — только CLI
- CLI не знает про `/creative`, бриф и аппрувы — он исполнитель одной операции
- `skills/gcv-kie` не дублирует контракт — он описывает **особенности kie**
  (какие модели для чего, какие подводные камни), а не форму команд
- MCP не содержит логики — если что-то есть в MCP и нет в CLI, это баг

## Точки расширения

| Что | Где |
|---|---|
| Новый сервис | скилл `gcv` → `templates/cli-template` → пакет `gcv-{svc}` |
| Новое хранилище | `settings.storage.adapter` |
| Новая политика роутинга | `skills/creative/references/routing.md` |
| Десктопная обёртка | импорт модулей `src/` порождённого пакета напрямую |
